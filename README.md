# Collective Memory MCP + AI Support Brain — Public Metadata

This repository is a **safe public metadata mirror** for the Collective Memory MCP and AI Support Brain showcase.

It contains high-level, non-sensitive system metadata used by the showcase webpage: component names, agent roles, capabilities, and technology labels. It intentionally does **not** contain the private integration source, credentials, customer data, or internal implementation details.

The showcase reads repository metadata from GitHub's public API, including stars, forks, open issues, primary language, last update time, recent commits, and the `SHOWCASE_METADATA.json` manifest.
